Lab cost model — transcribed from the game bundle
speedvb(e,t) = (1 + 0.02·e)(1 + t/100)  e = Labs Speed level, t = relic %
timeDURATION / vb · (1 − percentComplete)
coinsCOST · (1 − labDiscount · 0.3 / 100)
gem disc.Cb(o) = 1 / (1 + 0.015·o)  o = gold boxes opened
rush gems⌈ _b(time) · Cb(o) ⌉  _b is piecewise linear in seconds remaining
yours

Two exemptions live inside the same function: the Labs Speed lab is not sped up by itself, and the Labs Coin Discount lab is not discounted by itself.

      Where every number on this page comes from
      

        
Tier A
          TowerSmith — GOD tables
          
The root source. Per-level JSON for 48 workshop stats and 217 lab researches, extracted from the
            game's own upgrade tables and verified against its upgrade display. Not curve fits — real tables.
            tables/workshop/, tables/labs/. CC BY-NC-SA 4.0.

        
Tier A
          The game bundle, via mytower.app
          
The lab cost/time/gem model is code, not a table. Recovered from the deobfuscated Vite bundle and
            transcribed character-for-character — that transcription is what the Formulas tab shows.

        
Tier B
          The Tower Unified Tools
          
Best secondary source. Pre-extracted JS tables for workshop costs and values, workshop enhancements,
            labs, modules, bots, cards, milestones, relics — plus the regression gates that check the bundle
            transcription against the published wiki tables. CC BY-NC-SA 4.0.

        
Tier B
          tower-calculator
          
Narrower, and useful for it: in-run battle upgrade cash tables for 13 stats, plus 5 lab
            multiplier curves.

        
Tier B
          The Tower Optimizer
          
A third independent extraction pipeline. Not imported — kept as something to diff against.

        
Tier C
          Fandom wiki
          
Workshop Upgrades, Lab Upgrades, Workshop Enhancement, Damage. Its published gem-rush and
            Elite-Cell tables are the reference the bundle transcription is tested against.

        
Tier C
          Game Vault wiki
          
Guide-grade mechanics and upgrade priority. Explains; doesn't supply data.

        
Tier C
          Tower Hub
          
Browsable per-level cost tables — handy for eyeballing a single stat by hand.

      

      
Full write-up, including the licensing terms and the known gaps, is in
        research/THE-TOWER-SOURCES.md.
