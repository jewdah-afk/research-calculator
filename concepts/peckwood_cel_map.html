Rules

  • Ink outlines: Highlight per WorldTree group (OutlineColor #0c0817, OutlineTransparency 0, FillTransparency 1, DepthMode Occluded; ≤ 31 live). Hero cards (hen, eggs, landmarks) also get an inverted-hull outline mesh for inner lines.
  • 2-step cel, no gloss: SmoothPlastic only, two colours per part (base + hard shadow face). Lighting: EnvironmentDiffuseScale 0, EnvironmentSpecularScale 0, Ambient + OutdoorAmbient high so faces stay flat, Brightness 2.
  • Hard shadows: GlobalShadows false, CastShadow off everywhere. Each prop gets a flat ellipse (cylinder Part 0.05 thick, colour ink, Transparency 0.66) offset north-east; hill drops paint a grass-shadow band on the lower tile.
  • Post: ColorCorrection Contrast 0.4, Saturation 0.45 (= CSS 140 % / 145 %).
  • Neon nodes: Material Neon #ff007f tile + PointLight (Range 10, Brightness 3) + Lighting BloomEffect (Intensity 1, Size 24, Threshold 0.95). Pulse = TweenService on the light Brightness.
  • Halftone: ScreenGui (IgnoreGuiInset, DisplayOrder 0) → full-screen ImageLabel, ScaleType Tile, TileSize 4×4 px, ImageTransparency 0.93, a 4×4 dot texture (upload). It stays fixed while the world pans.
  • Parallax 0.3×: background models (stars, far silhouettes) move by camera offset × 0.3 each RenderStepped.
  • Cards: trees and props are flat cards that face the camera: a thin MeshPart with the card image (SurfaceAppearance ColorMap, AlphaMode Transparency), yawed to the camera once (fixed camera, so no per-frame cost).
