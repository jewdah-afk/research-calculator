Header banner (painted cave + parallax)
One ImageLabel (the painted cave banner, 1680×560 upload) in a ClipsDescendants header, ScaleType Crop; Position nudged from the mouse (±13 px x, ±4 px y). A dark centre shade ImageLabel (softellipse) sits behind the title; the 4 px ink edge stays on top.
Light sweeps (header, START, rarity plates)
A thin Frame with a white-centre UIGradient, Rotation 20, its Position (or the UIGradient Offset) tweened across a ClipsDescendants parent. No skew needed.
Gradient title with ink outline
TextLabel + UIGradient (white → gold) + UIStroke 3 px ink + a second offset label for the drop.
Depth parallax + 3D boss
The arena painting is cut into 3 layers (far cave, altar + arch + braziers, foreground crystals; the far plate is inpainted behind the others). Each layer is an ImageLabel whose Position eases toward the cursor by its depth (5 / 12 / 15 / 30 px) plus a slow idle camera drift (RenderStepped lerp). The Giant Black Pudding is a real 3D model (here modelled in code from its icon; in game a MeshPart + a black flipped-normal hull MeshPart for the ink outline) in a ViewportFrame WorldModel on the altar layer: it breathes, its crown stalks sway, it blinks, turns toward the cursor and squash-pops in on floor change. Other bosses use their icon until their models exist.
Boss stage
A painted arena ImageLabel (same family as the header art) with the boss's own game icon standing on the rune circle. Spotlight beam = a beam-shaped gradient ImageLabel swaying by Rotation; floor glow = a softellipse ImageLabel pulsing Size + transparency; mist = two softellipse ImageLabels drifting; embers = star ImageLabels rising. Floor switch = a black Frame flash 0.55 → 1 + the boss drops in. Cursor parallax: arena −10 px, boss +14 px + Rotation. Idle squash/stretch is on the boss only (keys never squash). Boss down = ImageTransparency 0.55.
Styles
Steel and Amethyst are the same frames with different colour tokens (UIGradient ColorSequences + a 2 px gold inner UIStroke on a child Frame for the Amethyst trim). Theme = one table swap in Kit.
CLEARED slam + shake + shockwaves
One TextLabel stack per letter tweened in turn (Back easing); root Frame Position jitter for 0.4 s (and a small camera shake); shockwave = a ring ImageLabel growing + fading, one from START and one from the title; card bursts = 7-14 star ImageLabels flying out; "+amount" TextLabels rise off the wallet chips.
Sparkles
16 ink-outlined 4-point star ImageLabels (fx/sparkle) rising on looping Position tweens; Size twinkles. No per-frame Lua.
Keys
Kit.button: ink body, lip, face. Press-in moves body top, face and glint down 6 px and hides the lip (no squash). Hover = a white Frame on the face at 0.91 transparency. Cursor glint = a ui/softellipse ImageLabel inside the face, Position = mouse − AbsolutePosition.
Rarity plates
The tile's own fill is the rarity (UIGradient: blue, purple, gold; mythic = rainbow ColorSequence) inside the ink UIStroke, plus the sweep band above. No rotating borders, no glows.
Selected floor
Selected row gets a lighter fill, a 6 px gold bar and a gold UIStroke frame that tweens to the row; other rows' icons sit at ImageTransparency 0.22 and their names in grey.
Locked things
Grey copies of the icons are separate uploads (quest_floor_locked, parrot_locked) with a drawn padlock ImageLabel on the corner. No runtime desaturation.
Numbers
Motion.roll rolls values; timers and counters use one TextLabel per digit at a fixed width so nothing jitters (Fredoka One digits aren't monospaced). Suffix = a second TextLabel at 65 % size in gold.
Reward moment
Flash = a full-screen softellipse ImageLabel alpha tween; rays = rotating ImageLabel (ui/rays, fade baked into the texture); drop cards flip open with a Size X tween from 0; coins fly on a Bezier with TweenService (Motion.flyTo) from below the cards, cards ZIndex above the coins; wallet chips pulse (UIScale).
World blur behind windows
Lighting BlurEffect Size 0 → 8 + ColorCorrection Brightness −0.25 while a window is open.
BW2 area sign
ScreenGui frame slides from Y −1 → 0 with Back easing on island change, holds 2.2 s, slides out.
Window open / close
