# Overgrown Incremental: Name Proposals

Every name from the old game gets a new Overgrown Acres name. The format is **Old > New**. Only display names change; the internal code and datastore names stay the same, so saves and scripts keep working.

**Game:** Ascension Incremental / Stud Incremental > **Overgrown Incremental**

## 4. Upgrades

All 248 upgrades are named `Currency_Target` in code. Rename them with one rule: the new currency name, then what it boosts.

| Code name | New display name |
|---|---|
| Flesh_Energy | **Compost: Sap** |
| Prisms_RuneLuck | **Pollen: Seed Luck** |
| Orbs_SpawnLevel | **Spores: Pod Spawn Level** |
| Chromium_Prisms4 | **Chlorophyll: Pollen IV** |
| RP_Energy2 | **Soil: Sap II** |
| AP_Droplets1 | **Frostsoil: Dew I** |

Board titles follow the same rule:
- ENERGY UPGRADE > SAP UPGRADE
- FLESH UPGRADE > COMPOST UPGRADE
- PRISMS UPGRADE > POLLEN UPGRADE
- and so on for every currency

Upgrade groups and tags:

| Old | New |
|---|---|
| Talent upgrades (Prisms_* / Chromium_* in the tree) | **Roots** in the Root Web |
| Permanent upgrades / [PERMANENT] | **Perennials / [PERENNIAL]** |
| Overclock (e.g. "Spheres Overclock") | **Overgrow** ("Acorn Overgrow") |
| Supercharge (e.g. "Prisms Supercharge") | **Surge** ("Pollen Surge") |
| Enhance (e.g. Prisms_OrbsEnhance) | **Graft** ("Pollen → Spore Graft") |
| AutoBuy | **Auto-Tend** |
| Milestone | **Milestone** (stays; "Acorn Milestone #1") |
